# 源模型验证场景完成记录

2026-09-08：根据用户要求制作源模型验证场景。

## 交付

- `blender/source_validation/source_validation.blend`（约 3.4 MB）：可直接打开播放，0–599 帧、60 FPS，默认第 120 帧总览。
- 同目录 README、8 张关键帧渲染、`validation.json`。
- `tools/build_source_scene.py`：从录制及 MJCF/STL/OBJ 重建场景，支持 `--motion`、`--output`、`--render`。
- `tools/verify_source_scene.py`：在重新打开的 .blend 上做独立校验。

## 实现

32 个已录制节点直接保留世界位置/旋转；34 个手部网格按 MJCF 的 geom 位姿和 mesh scale 挂载。掌部、10 个指尖及 RH:pick 从固定子节点偏移还原，未录制的 wrist_dx/dy/dz 不用于猜测姿态。

吉他根节点使用 MJCF 固定变换，保留两个琴颈网格、弦枕、22 品及源琴身方盒；琴弦按 MJCF 端点绘制。拨弦范围以线框显示，拨片仅有黄色参考点。蓝色左手、橙色右手，提供三个按整个片段抽样范围取景的检查相机。

动画逐帧关键帧采用线性插值，不加平滑；对 reset 或四元数符号不连续的输入明确拒绝，避免不正确拼接。没有调整仿真数据或角色重定向。

## 验证

Blender 5.2.1 后台构建及渲染通过。600 帧共 32 节点的位置误差为 0，四元数分量误差最大约 2.94e-7，固定层级矩阵误差最大约 1.19e-7。

重新启动 Blender 打开保存文件，8 个关键帧、固定指尖/拨片偏移，以及 36 个源网格（34 手部 + 2 琴颈）的原始表面顶点范围、局部缩放和偏移核对通过。OBJ 校验仅比较被面引用的顶点：两个琴颈 OBJ 包含未使用顶点，Blender 导入时会剔除。

已查看总览、左右手第 120 帧及左手第 570 帧渲染，修正了首次左手检查相机取景偏离的问题。保存场景不依赖外部 JSON 或脚本播放。

## 限制与后续

本阶段确认空间变换与源几何还原；不等于按弦准确率或穿透质量已验收。吉他姿态未录制，按源模型静态值恢复；绿色/黄色参考点不表示发生了真实接触。原始快速指节变化保留，下一步应结合曲谱事件判断接触，再完善整曲录制和目标角色适配。
